# Examples

- `sample_rr.csv` — 376 synthetic resting RR intervals (~5 min, mean
  ~800 ms). Generated with `examples/generate_sample.py`-equivalent
  code: RSA oscillation 0.25 Hz (25 ms) + Mayer wave 0.1 Hz (15 ms) +
  Gaussian noise sigma 8 ms, seed 42. Clearly synthetic; used to
  demonstrate the CLI and the plots.
- `nsr16265_rr.csv` — real NN intervals: first 5 minutes of record
  16265, MIT-BIH Normal Sinus Rhythm Database (PhysioNet), 128 Hz
  annotations, only N-N intervals kept (see `docs/RESEARCH.md`).
- `example_output.txt` — real CLI output on `sample_rr.csv`.
- `nsr16265_output.txt` — real CLI output on `nsr16265_rr.csv`.
- `tachogram.png` / `psd.png` — plots of the synthetic example,
  generated by `plot_examples.py` (run from the project root).
- `generate_sample.py` — regenerates `sample_rr.csv` (seed 42).
- `plot_examples.py` — regenerates the two plots.
